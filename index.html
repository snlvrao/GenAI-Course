Start here

Setup asks which of three paths you want first: fully offline (a model on your own machine, no account), free hosted (a free key, no card), or your own key. It then shows only the steps for that path.

After that, go to Module 1 and work through in order. Each module’s build reuses the one before it, so by Module 18 you are assembling parts you already wrote rather than starting from an empty file.

Open the course with Start course.cmd (or python start.py). The pages work if you double-click them, but the videos do not: YouTube will not run its player in a page opened as a file. The launcher serves the course on your own machine and opens it, which is all the videos need. Nothing is uploaded and nothing is installed.

Two rules this course follows

No vendor lock-in

Labs run against a free hosted model, a paid one, or a model on your own laptop with no account and no internet. You switch by editing one line in .env, never the code. The MCP servers you build are proved with a Python client you write yourself, so Claude Desktop, Cursor and VS Code are optional extras.

Uncertainty is stated

Where a claim is contested, or a number comes from a company with an interest in it, the notes say so. Where no good video exists, the module says so instead of padding. Prices and versions carry the date they were checked.

Your progress

Everything is stored in this browser on this computer. Nothing is uploaded anywhere and there is no account. That also means clearing your browser data will clear it, so export a copy if you care about it.
